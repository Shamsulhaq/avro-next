# Changelog

## Unreleased

- Settings: links to the project, problem reports and contributing; developer credit in the About line.
- Contributor docs (CONTRIBUTING.md), issue and pull request templates, and CI that builds and tests every pull request.

## 0.1.4

- Update notifications: Avro Next checks GitHub daily and notifies you when a new version is out. Install it from the notification or the input menu ("Install Avro Next x.y.z…"). Downloads are verified with SHA-256 before the installer opens.
- Settings > Updates: turn automatic checks on or off, include or skip pre-releases, and check now.

## 0.1.3

- Avro Next's own compact candidate bar replaces the system one. Arrow keys now move between suggestions reliably, and a click commits a word.
- Fixed remembered choices: the word you pick becomes the default the next time you type it.
- Settings window: compact layout that resizes to fit; Probhat-only options appear only for Probhat.
- Installer always installs to `/Library/Input Methods` and registers the input source.

## 0.1.0

- First version: Avro Phonetic, Khipro and Probhat layouts on the riti engine, settings window, installer DMG.
